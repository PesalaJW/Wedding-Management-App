Wedding projects

Each project is a completely separate wedding — its own budget, guest list, checklist, and agenda. Useful for a couple with two separate functions (e.g. wedding and homecoming at different hotels), or for managing more than one couple's wedding from one account.

Create a new project

This creates brand-new Bride and Groom logins for this project. To reuse an account that already exists on the platform, open the project once created and use "Add existing user" instead.

Backups

Keep a full copy of everything (every project and login) somewhere safe, or restore one. When cloud sync is on, the app also keeps up to 14 daily snapshots in the shared database on its own — no extra setup beyond the rule in the README.
